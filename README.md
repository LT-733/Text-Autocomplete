# So how does it work?
Text diffusion models are supposedly faster than autoregressive models in terms of tokens per second. The core technology used in training diffusion models, be it image or text, is **denoising**. Suppose you have an embedded string and you are to let the model recreate that exact string. What you can do, is to add some "noise", or mask some parts of the original tensor. This masking is applied with uniform random probabilities, and this masked tensor will be fed into the feed-forward network. 

The feed-forward network gets the data, it will first use a tensor, which on startup, is randomly generated, of shape [length of hash set, embedding dimension] to embed the input tensor, which are simply encoded by using a hashset to assign an integer to each character. Once that is done, we first normalize the embedded tensor, then create a fused QKV batch out of it using a linear layer to extend the size of the last dimension of the normalized tensor by three times, then we split the tensors uniformly and apply attention to it using the formula from _Attention is All You Need_. Then we normalize again, and use a traditional linear layer + activation function + linear layer to infer the result, before using a fully connected layer to get the length of the last dimension of the tensor in question to the size of the hashset again, so that we can calculate the loss per token on all our letters.
